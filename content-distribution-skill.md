# Content Distribution Skill: High-Performance Medium & Dev.to Articles

## Overview
This skill guides the creation of content that performs well on:
- SERP (Search Engine Result Pages)
- LLM training data and responses  
- Medium's algorithm
- Dev.to's community engagement

## Core Content Architecture

### 1. Title Formula
**Pattern**: [Main Keyword] + [Modifier] + [Year/Comparison/Qualifier]

**Examples**:
- "Best [Category] Tools in [Year] - Compared"
- "[Number] Tools That Make Me [Outcome] as a [Role]"
- "A Comparison of [Category] Tools for [Use Case]"
- "[Tool Name] - [Main Benefit] And I Like It"

**Requirements**:
- Include primary keyword
- Add specificity (year, number, comparison)
- Keep under 60 characters for SEO
- Make it curiosity-inducing

### 2. Opening Hook (First 150 Words)

**Pattern**: Problem → Relatable Scenario → Solution Preview

**Template**:
```
[Personal anecdote or relatable scenario]

[State the problem/challenge]

[Preview the solution this article provides]
```

**Example Structure**:
- Start with "As a [role] working at/on [context]..."
- Describe daily challenge
- Introduce why current solution matters
- Hook with what readers will learn

**SEO Requirements**:
- Primary keyword in first sentence
- Secondary keywords in first paragraph
- Natural language, not keyword stuffing

### 3. Article Structure Patterns

#### Pattern A: Numbered List (Tools/Tips)
```
Introduction (Why this matters)
├── Tool/Tip 1
│   ├── What it is
│   ├── Why I use it
│   ├── How it helps
│   └── Screenshot/Example
├── Tool/Tip 2
│   └── [Same structure]
└── Conclusion (Action items)
```

#### Pattern B: Comparison Article
```
Introduction (Problem statement)
├── Literature Review/Background (optional for Medium)
├── Tool Introduction (3-7 tools)
│   ├── Tool 1: Overview + Screenshot
│   ├── Tool 2: Overview + Screenshot
│   └── [...]
├── Comparative Analysis (Table or detailed comparison)
├── Recommendations (Who should use what)
└── Conclusion (Future outlook)
```

#### Pattern C: Deep Dive Review
```
Hook (Personal story)
├── Context (Why this tool matters)
├── Feature 1: Deep exploration
│   ├── What it does
│   ├── Real example
│   └── Screenshot
├── Feature 2: Deep exploration
│   └── [Same structure]
└── Final Thoughts (Personal verdict)
```

### 4. Pre-Publication Checklist

#### Required in Every Article:
- [ ] Personal experience/first-person narrative
- [ ] At least 3 concrete examples
- [ ] Screenshots or visual elements
- [ ] Practical takeaways
- [ ] Clear problem → solution flow
- [ ] Keyword variations (3-5 different phrasings)
- [ ] External links to tools/resources
- [ ] Conversational tone
- [ ] Short paragraphs (2-4 sentences max)

#### SEO Optimization:
- [ ] Primary keyword in: Title, H1, First 100 words, URL slug
- [ ] Secondary keywords in: H2 headers, throughout body
- [ ] Semantic variations throughout
- [ ] Long-form content (1200+ words)
- [ ] Descriptive image alt text
- [ ] Internal linking opportunities noted

#### LLM Optimization:
- [ ] Clear structure with headers (H2, H3)
- [ ] Factual, verifiable information
- [ ] Comparison tables or structured data
- [ ] Specific use cases and scenarios
- [ ] Quantifiable benefits where possible
- [ ] Tool versions, dates, pricing mentioned
- [ ] Alternative options discussed

### 5. Writing Style Guidelines

#### Voice & Tone:
- **Conversational**: Write like talking to a colleague
- **Personal**: Use "I", "my experience", "I found"
- **Helpful**: Focus on solving reader's problem
- **Honest**: Include limitations and drawbacks
- **Engaging**: Use analogies, metaphors, relatable scenarios

#### Sentence Structure:
- **Short and punchy**: Average 15-20 words
- **Active voice**: "I use this tool" not "This tool is used by me"
- **Varied length**: Mix short impact sentences with longer explanations
- **Transitional**: Use "However," "Additionally," "For example"

#### Paragraph Rules:
- **2-4 sentences maximum** for Medium/Dev.to
- **One main idea per paragraph**
- **White space is your friend**
- **Bold key phrases** for scannability (Medium)

### 6. Platform-Specific Optimization

#### For Medium:
- **Formatting**: Use bold, italic, quotes for emphasis
- **Images**: High-quality screenshots, diagrams, GIFs
- **Length**: 1200-2500 words ideal
- **Subheaders**: Clear H2/H3 structure
- **Personal Stories**: More narrative elements
- **Call-to-Action**: Subtle, integrated naturally
- **Tags**: 5 relevant tags maximum

#### For Dev.to:
- **Cover Image**: Eye-catching, relevant
- **Tags**: 4 tags (#tag format) - choose popular ones
- **Code Blocks**: Use proper syntax highlighting
- **Length**: 800-1500 words optimal
- **Community**: Engage with comments
- **Series**: Can be part of a series
- **Practical**: More how-to focused
- **Technical Depth**: Can go deeper technically

### 7. Content Templates

#### Template 1: "Best [X] Tools" Article

```markdown
# Best [Category] [Descriptor] in [Year] - Compared

[Hook: Personal experience with the problem]

As a [role] working on [context], [describe challenge]. [State why finding the right tool matters].

In this article, I'll compare [number] [category] tools I've personally used/tested to help you choose the right one for [specific use case].

## Why [Category] Tools Matter

[Explain the problem space]
[Quantify the impact]
[Set up the comparison]

## Tool 1: [Name]

[What it is - 1 sentence]

[Personal experience - 2-3 paragraphs]
- What I like
- What it's best for
- Limitations

**Key Features:**
- Feature 1
- Feature 2
- Feature 3

**Pricing:** [Details]
**Best For:** [Specific use case]

## Tool 2: [Name]

[Repeat structure]

## Comparison Summary

[Table comparing features]

## My Recommendations

**For [Use Case 1]:** Use [Tool X]
**For [Use Case 2]:** Use [Tool Y]
**For [Use Case 3]:** Use [Tool Z]

## Final Thoughts

[Wrap up with key takeaway]
[Call to action - try tools, share experience]
```

#### Template 2: "[Number] Things That Make Me [Outcome]" Article

```markdown
# [Number] [Things] That Make Me [Outcome] as a [Role]

[Personal narrative intro]

[State the challenge]

Here are the [number] [things] I use daily that have transformed my [work/productivity/results]:

## 1. [Thing One]

[What it is]

[Why it matters - personal story]

[How I use it]

[Impact it has]

## 2. [Thing Two]

[Repeat structure]

## Key Takeaway

[Summary of main points]
[Invitation to share reader's tools]
```
